## `ventana-produccion-estilos.html`

Prueba de estilo para el gráfico «La ventana de producción», que pertenece a otro
proyecto. Aquí sólo se reconstruye para comparar tres tratamientos de las barras
sin tocar el original:

| | Estilo | Marca |
|---|---|---|
| 01 | Mosaico | teselas sólidas de esquina dura sobre un damero muy tenue |
| 02 | Cronograma | línea de 10 px, tramos por fuente, marcador cuadrado al cierre |
| 03 | Data blocks | bloques adyacentes con 3 px de separación y etiquetas tipo tag |

Los tres comparten datos, textos y estructura (once piezas × cuatro sistemas ×
doce columnas). Se cambia sólo la marca gráfica.

Ábrelo directamente en el navegador; es un único archivo sin dependencias.
